### Roomie: a UX case study

**Live:** [roomie-case-study.vercel.app](https://roomie-case-study.vercel.app)

</div>

**Fair isn't equal.** How a household chore app went from "who keeps doing the dishes?" to a system nobody has to police. The case study follows the design-thinking process end to end:

| | Phase | The one line |
| --- | --- | --- |
| 01 | Empathize | The chore isn't the hard part. Asking is. |
| 02 | Define | Fairness is effort, not count. |
| 03 | Ideate | 25 ideas in. Eight made the cut. |
| 04 | Prototype | Designed to lower the temperature. |
| 05 | Test | Six flatmates. Forty minutes. No help. |
| 06 | Reflect | Scores inform. Context decides. |

Ideate explains the rules behind the system, with flowcharts for how chores get split each week and how the daily house streak works.

## Stack

Next.js 16 · React 19 · TypeScript · GSAP. Diagrams and flowcharts are hand-built SVG, so they stay sharp and accessible.

## Run

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```
