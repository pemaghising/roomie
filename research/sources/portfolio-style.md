# pemaghising.com.np: style notes (from live CSS, 2026-09-26)

Next.js + Tailwind. Tokens are in `portfolio-site.css`.

- **Colour:** background `#121212`, surface `#181818`, primary text `#f5f5f5`, secondary text `#a3a3a3`, one accent `#a855f7` (purple). Dark only.
- **Type:** Inter for UI and body; Instrument Serif for display and editorial moments; mono (`ui-monospace`) for labels.
- **Grid:** `grid-template-columns-editorial: repeat(12, 1fr)`; containers up to 42rem for reading width.
- **Spacing:** Tailwind 4px base (`--spacing: .25rem`); generous whitespace between sections.
- **Motifs:** numbered section labels (`PG/01`–`PG/09`); motion-led rather than photo-led.
- **Tone:** short, confident, plain. Examples: "Design that moves", "Clarity over decoration", "Tools are just tools". Hero: "I turn ideas into visual systems, stories, and experiences that communicate clearly and move people."
- **Gap:** no existing case-study template, so Roomie will be the first long-form page.
