# Onboarding illustrations: 10 prompts for ChatGPT

One illustration per onboarding step, all in the same soft clay 3D style as the Roomie mascot and the plant stages.

**How to run each one**
1. Open a **new ChatGPT chat** for each prompt.
2. Attach `brand/marketing/refs/mascot.png`. Where a prompt says so, also attach a plant image from the same folder.
3. Paste the whole grey box.
4. Download the PNG and save it as `C:\Leapfrog\Bootcamp\Img assets\CHAGPT\O<number> <name>.png`, then send Claude the path. Claude trims it, checks the transparency and places it in the app, Figma and the case study.

**If something comes out wrong**
- **The mascot looks different:** reply "Use the attached mascot exactly: same face, roof colour, door and chimney sprout."
- **The background isn't transparent:** reply "Same image, transparent background, no floor and no shadow plate."
